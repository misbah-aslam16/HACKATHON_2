🚀 QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Read the main guide
   → Open: START_HERE.md

STEP 2: Choose your deployment method
   
   Option A: Quick Manual Deployment (15 minutes)
   ─────────────────────────────────────────────
   Best for: Getting started quickly, testing, development
   
   Windows:
   cd infra\gcp
   setup-gcp.bat
   deploy-all.bat
   
   Linux/Mac:
   cd infra/gcp
   chmod +x *.sh
   ./setup-gcp.sh
   ./deploy-all.sh
   
   
   Option B: Production with Terraform (15 minutes)
   ────────────────────────────────────────────────
   Best for: Production, infrastructure as code, team collaboration
   
   cd infra/gcp/terraform
   cp terraform.tfvars.example terraform.tfvars
   # Edit terraform.tfvars with your values
   terraform init
   terraform apply
   
   
   Option C: Automated with GitHub Actions (15 minutes setup)
   ──────────────────────────────────────────────────────────
   Best for: Continuous deployment, automated workflows
   
   Windows:
   setup-cicd.bat
   
   Linux/Mac:
   chmod +x setup-cicd.sh
   ./setup-cicd.sh
   
   Then:
   - Add GitHub secrets (see CI_CD_SETUP_GUIDE.md)
   - Push to main branch
   - GitHub Actions runs automatically

STEP 3: Verify deployment
   gcloud run services list --region us-central1

STEP 4: Test your application
   Open the frontend URL in your browser
